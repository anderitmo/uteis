# Repositórios e Ferramentas Úteis

Interface moderna, rápida e responsiva para organizar e acessar as melhores ferramentas hospedadas no GitHub.

## 🚀 Ferramentas Incluídas

- **TextTools**: Diversas ferramentas para manipulação de textos com recursos de Markdown.
- **Estatística para Pesquisadores**: Calculadoras úteis para pesquisas quantitativas.
- **MDView**: Visualizador de Markdown com suporte a artigos e postagens.
- **FREQLAB**: Analisador de espectro de áudio MP3 em tempo real.
- **AuraSpectrum**: Analisador de espectro de áudio MP3 com detector de pitch.
- **Polaroid Studio**: Criador de quadros e fotos estilizadas no formato Polaroid.
- **LM Studio Interface**: Interface web para conectar a modelos de IA locais executados no LM Studio.
- **KeyCraft**: Gerador seguro de senhas fortes, PINs e chaves aleatórias.
- **ImageTools**: Suíte para compressão, conversão de imagens e edição de metadados EXIF.
- **MergePDF**: Ferramenta para juntar e combinar dois ou mais arquivos PDF.

## ✨ Funcionalidades

- **Favoritos com Reordenação**: Marque qualquer ferramenta como favorita para posicioná-la automaticamente no início da lista.
- **Persistência**: Suas preferências de tema e lista de favoritos são salvas diretamente no `localStorage` do seu navegador.
- **Light e Dark Mode**: Alternância fácil entre modo claro (fundo branco, cores neutras) e modo escuro.
- **Filtro de Busca em Tempo Real**: Busque ferramentas instantaneamente por título, descrição ou categoria.
